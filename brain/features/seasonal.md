# Seasonal events

Advanced settings › Seasonal events › **Spooky doot** talks to [doot](https://github.com/boubou666/doot),
a Halloween skeleton app, if it is installed. Disabling takes two questions (the second swaps its
buttons), plays one last doot, then snoozes doot for a century; Enable resumes it. doot only takes
broadcasts from holders of `DUMP`, which `install.sh` grants.
